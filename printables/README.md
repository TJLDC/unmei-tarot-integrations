# タロット3枚引きの記録シート

過去・現在・未来の3枚引きを、印刷して手書きで残せるA4シートです。引く前の問いと、カードごとに読み取ったこと、あとで読み返して気づいたことを1ページに記録できます。

[A4シートをダウンロード（PDF）](https://github.com/TJLDC/unmei-tarot-integrations/releases/download/printable-ja-v1/tarot-three-card-worksheet-ja.pdf)

## 使い方

1. 日付、デッキ、問いを書きます。未来の流れを読み返すために、「今月末まで」などの目安も残します。
2. 3枚を引き、過去、現在、未来の欄にカード名と向きを記録します。それぞれの位置で、カードが問いに何を伝えたかを書きます。
3. 3枚をつなげて見えた流れを書き、読み返す日を決めます。あとからわかったことは、下の欄に追記できます。

印刷する場合は、用紙サイズをA4に設定してください。1枚引きの記録欄や書き方の例も使いたい方は、[タロットノート](ja.md)をコピーできます。
